# pt
## Resumo
- Voto: o PokeIdle agora conta os votos no IdleHub. O botão de cada conta já abre o IdleHub ("Votar no IdleHub").
- Perfis de jogo: novo campo "Site de votação" ao criar ou editar um perfil.

## Detalhes
### Voto no IdleHub
- O PokeIdle trocou o TopIdle pelo IdleHub (idlehub.io). Todos os perfis do PokeIdle passaram para o IdleHub sozinhos; a contagem de 24 h de cada conta continua de onde estava.
- O botão continua abrindo a página de voto com a sessão da conta. Quem vota é você; o app não clica em nada.
- Quando o IdleHub mostra "Voto registrado", o botão já começa a contar as 24 h. O tempo que falta também vem do próprio jogo, então vale até para votos feitos fora do app.

### Site de votação no perfil
- Ao criar ou editar um perfil de jogo, o campo "Site de votação (opcional)" diz qual página o botão de voto abre.
- Um perfil novo do PokeIdle já vem com o IdleHub preenchido. Deixe o campo vazio para tirar o botão de voto.

# en
## Summary
- Voting: PokeIdle now counts votes on IdleHub. Each account's button already opens IdleHub ("Vote on IdleHub").
- Game profiles: new "Voting site" field when creating or editing a profile.

## Details
### Voting on IdleHub
- PokeIdle replaced TopIdle with IdleHub (idlehub.io). Every PokeIdle profile moved to IdleHub on its own; each account's 24 h countdown carries on where it was.
- The button still opens the voting page with the account's session. You vote; the app clicks nothing.
- When IdleHub shows "Vote counted", the button starts the 24 h countdown. The time left also comes from the game itself, so it works even for votes made outside the app.

### Voting site in the profile
- When creating or editing a game profile, the "Voting site (optional)" field sets which page the vote button opens.
- A new PokeIdle profile comes with IdleHub already filled in. Leave the field empty to remove the vote button.
