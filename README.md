# BookIdle

Gerenciador de contas do pokeidle.io (várias contas lado a lado, modos de janela, voto no TopIdle, sniper do mercado e mais).

## Instalar

1. Abra a aba **Releases** (à direita) e baixe o arquivo **BookIdle-win-Setup.exe** da versão mais recente.
2. Rode o instalador. Na primeira vez o Windows pode mostrar "O Windows protegeu seu PC": clique em **Mais informações** e depois em **Executar assim mesmo**.
3. O BookIdle se atualiza sozinho: quando sair uma versão nova, ele avisa e atualiza com um clique.

Cada pessoa usa as próprias contas; nada é compartilhado.
